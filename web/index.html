How the demo stays honest

  • Every measurement is replayed from the archived fixtures under demo/clips/ — no model calls, no OpenCV, no AWS.
  • An upload is recognised by its SHA-256 — the same key the live matte cache uses — and never leaves the browser.
  • The loop enforces what the agent may not skip: every process is verified, every fix re-inspected, delivery refused unless the latest verification passed.
  • Every number is measured — Ethel's second attempt, the last projected one, was measured on 2026-09-19 (1.52×). A fixture that were projected would say so and be tagged projected; none is.
  • OpenCV 5 DNN subject segmentation / QC is the first live capability to wire — planned, not running here.
